OnlineTest
موقع محلي صغير على http://onlinetest.local:5088
الاسم onlinetest.local يشير إلى 127.0.0.1 في ملف hosts.
الصفحة تقول: الموقع شغال / The site is online.

تسجيل الدخول
اسم المستخدم: developer
كلمة المرور: developer
إذا كانت كلمة المرور خاطئة تبقى في صفحة الدخول وتظهر رسالة بالعربية.
بعد الدخول: صورة، وجدول بالاسم والملاحظة، وأزرار حفظ وتعديل وحذف.
زر تسجيل الخروج يعيد صفحة الدخول.
البيانات تُحفظ في records.json داخل هذا المجلد.
الصورة في picture.png وتظهر بعد الدخول فقط.

التشغيل على هذا الجهاز
1. انقر اختصار OnlineTest على سطح المكتب.
   تفتح نافذة أوامر وتشغّل الموقع، ثم يفتح المتصفح على العنوان أعلاه.
2. أو من مجلد C:\Users\user\Desktop\OnlineTest شغّل:
   dotnet run
3. فحص الجاهزية:
   http://onlinetest.local:5088/health
   الناتج المتوقع: ok
4. لإيقاف الموقع أغلق نافذة الأوامر، أو اضغط Ctrl+C داخلها.
5. يلزم تثبيت .NET SDK على الجهاز (الإصدار 10).

لاحقاً: نطاق واستضافة رخيصة
لا تشترِ شيئاً الآن. هذه خطوات للوقت الذي تقرر فيه النشر:
1. قارن أسعار أسماء النطاقات عند أكثر من مسجّل، ثم اختر اسماً فقط إذا احتجته.
2. قارن استضافة رخيصة تدعم ASP.NET Core، أو خادماً صغيراً (VPS).
3. جهّز ملفات النشر بهذا الأمر من مجلد المشروع:
   dotnet publish -c Release -o publish
4. بعد اختيار الاستضافة لاحقاً، ارفع مجلد publish إليها.
5. اربط النطاق من إعدادات DNS بسجل A أو CNAME يشير إلى عنوان الاستضافة.
6. بعد ربط النطاق، فعّل HTTPS بشهادة مجانية.

المطلوب الآن التشغيل على هذا الجهاز فقط، بدون شراء نطاق أو استضافة.
